# From Theory to Practice: Neural Networks

Code for the blog series [From Theory to Practice](https://johndorem.us/blog/from-theory-to-practice/), where 3Blue1Brown's neural network videos get translated into working Python and NumPy code, one post at a time.

## Contents

- `part1_feedforward.ipynb`: building the feedforward pass for a small, untrained network, first as a direct scalar translation of the video's equations, then rewritten with NumPy for speed.

More notebooks will be added as the series continues.
